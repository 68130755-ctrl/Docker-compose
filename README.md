# ระบบ Web-ML ตรวจจับการบุกรุกเครือข่ายด้วย Docker Compose

โปรเจกต์นี้เป็นการจำลองระบบ Web-ML สำหรับตรวจจับและจำแนกประเภทการบุกรุกเครือข่ายคอมพิวเตอร์ (Binary Classification: Normal vs Attack) โดยจำลองการทำงานของโมเดล Random Forest Classifier บนชุดข้อมูลมาตรฐาน NSL-KDD

## 🌐 ช่องทางการเข้าใช้งานและทดสอบระบบ
เมื่อทำการติดตั้งและสั่งรันระบบเรียบร้อยแล้ว สามารถเปิด Web Browser บนเครื่อง Windows เพื่อเข้าใช้งานและทดสอบระบบได้ทันทีผ่านลิงก์ต่อไปนี้:

หน้าทดสอบระบบ API Docs (Swagger UI): http://localhost:8585/docs

## 🏗️ โครงสร้างสถาปัตยกรรมระบบ (Architecture)
ระบบถูกออกแบบมาให้แยกส่วนการทำงานออกจากกัน (Decoupled Architecture) ตามมาตรฐานการ Deployment จริง ประกอบด้วย 2 คอนเทนเนอร์ (Containers) ที่ทำงานร่วมกันภายในระบบเครือข่ายจำลอง:

web_server (Nginx Container): ทำหน้าที่เป็น Reverse Proxy หน้าบ้าน คอยดักรับคำขอจากภายนอกผ่านพอร์ต 8585 แล้วทำหน้าที่คัดกรองก่อนส่งต่อข้อมูลเข้าไปให้ตู้แอปพลิเคชันหลังบ้านอย่างปลอดภัย

ml_api (FastAPI Container): ทำหน้าที่เป็น Web-API รันระบบภาษา Python อยู่ที่พอร์ตภายใน 8000 คอยรับข้อมูลอินพุตไปประมวลผลร่วมกับโมเดล Random Forest เพื่อส่งผลการทำนาย (Normal หรือ Attack) กลับมาในลักษณะ JSON

## 🚀 วิธีการสั่งรันระบบ (How to Run)
ตรวจสอบให้แน่ใจว่าได้ทำการเปิดโปรแกรม Docker Desktop บนเครื่อง Windows เรียบร้อยแล้ว (รอจนแถบมุมซ้ายล่างขึ้น Running สีเขียว)

เปิดโปรแกรม Terminal หรือ PowerShell เข้ามาที่โฟลเดอร์โปรเจกต์นี้ (Docker compose)

พิมพ์คำสั่งด้านล่างนี้เพื่อประกอบร่างสร้างอิมเมจและสั่งเปิดคอนเทนเนอร์ทั้งหมดให้ทำงานอยู่เบื้องหลัง (Detached Mode):
docker compose up -d --build
